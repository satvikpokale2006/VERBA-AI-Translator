# VERBA – AI Language Translator 🌐

VERBA is an AI-powered multilingual translation application designed to translate text between different languages using Natural Language Processing (NLP) and Deep Learning.

## 🚀 Features

- Multilingual text translation.
- AI-powered language translation.
- User-friendly interface.
- Support for multiple languages.
- Built using the NLLB-200 translation model.

## 🛠️ Technologies Used

- Python
- Google Colab
- Hugging Face Transformers
- Meta NLLB-200
- Gradio
- Natural Language Processing (NLP)

## 📂 Project Structure

```text
VERBA-AI-Translator/
│
├── VERBA.ipynb
└── README.md
```

## ⚙️ How to Run

1. Clone this repository.
2. Open `VERBA.ipynb` in Google Colab.
3. Install the required dependencies.
4. Run the notebook cells.
5. Enter text and select the required languages to translate.

## 🎯 Project Objective

To develop an AI-powered multilingual translation system that makes communication across different languages easier and more accessible.
